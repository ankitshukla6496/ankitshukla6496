### About

I build products where the hard engineering *is* the product — agentic systems, real-time apps, and applied ML — and I care as much about the architecture as I do about the user outcome it serves. Seven years at **Samsung R&D** took me from Software Engineer to **Chief Engineer**, shipping at scale; I'm now pairing that depth with an **MS in Product Management at Carnegie Mellon** to own the full arc from problem to launch.

I like taking a fuzzy problem, finding the sharp technical primitive underneath it, and shipping the smallest thing that proves the idea.

- 🔭 **Building** — multi-agent LLM pipelines, structured-output tooling, and real-time full-stack products.
- 🧠 **Deep in** — agent orchestration (fan-out/fan-in, tool use, schema-validated generation), applied deep learning, and DX.
- 🛠️ **How I work** — typed end-to-end, small composable modules, CI/CD from day one, ship → measure → iterate.
- 🎓 **Foundations** — BE (Hons.) Electronics & Communication, BITS Pilani.
